<h3>Greptile Summary</h3>

This PR activates the previously no-op BFD section in `support_bundle_commands.conf` by uncommenting the `PROC_NAME:bfd` block and adding three `show bfd` commands.

- `show bfd peers` and `show bfd distributed` are registered in `bfdd_vty.c` and belong correctly under this section.
- `show bfd static route` is registered in `staticd/static_vty.c`; at runtime `vtysh` will dispatch it to `staticd` correctly, but the output is captured in the BFD log file and the command will fail if `staticd` is not running while `bfdd` is.
